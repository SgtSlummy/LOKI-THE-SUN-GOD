# Kiki Run Note - 2026-06-03 Run 002

## Topic

Spacing and alignment in a one-page flyer.

## Why This Topic

Run 001 established the main focal point and reading order. The next beginner step is to tighten the grid so that the hierarchy stays stable when the layout gets cleaner, which is a direct way to learn how spacing and alignment support the message instead of competing with it.

## Key Learning Notes

- Alignment is a structural choice, not just an aesthetic one.
- White space helps separate groups and lets the eye understand what belongs together.
- A beginner layout gets better when one repeated edge does most of the organizing work.
- A neat grid is not enough by itself; the type still needs to remain readable and comfortable.

## Studio Process Principles

- Build the layout against a guide system first, then adjust the content to the system.
- Treat whitespace as an intentional design material that can clarify structure and rhythm.

## Beginner Assignment

### Title

Tighten the Flyer Grid

### Learning Objective

Rebuild the flyer from run 001 so the hierarchy is reinforced by clean alignment, consistent spacing, and clear grouping.

### Estimated Time

35-50 minutes.

### Materials / Tools

- Figma Free or Canva Free
- Layout guides or a simple grid
- Optional contrast checker
- Notes app or text editor

### Design Brief

Revise the same fictional community event flyer from the last run. Keep the same content, but make the page feel more orderly and easier to scan by using one repeated alignment edge and more intentional whitespace.

### Steps

1. Reuse the same copy and keep the page to one format.
2. Add a column or grid guide and pick one primary alignment edge for the text.
3. Separate the headline, support line, event details, and call to action with clearly different spacing.
4. Reduce any leftover gaps that make the page feel accidental or disconnected.
5. Compare the revised version with the earlier one and write down what changed in the reading order.

### Constraints

- Keep the same content from run 001.
- Use only one page.
- Use no more than two font families.
- Use at least one repeated alignment edge across all text blocks.
- Do not add decorative elements just to fill empty space.

### Deliverables

- One revised flyer image or PDF.
- One short comparison note explaining what changed and why.

### Reflection Questions

- Which alignment edge does the most work in holding the page together?
- Where did more whitespace improve clarity, and where did it create a new problem?

### Optional Stretch Challenge

Make a second version that changes only the alignment strategy, such as left-aligned versus centered text, and compare which version is faster to scan.

## Critique Rubric

| Criterion | 1 - Needs Work | 2 - Developing | 3 - Solid Beginner Attempt | 4 - Strong Beginner Work |
|---|---|---|---|---|
| Alignment consistency | Text blocks drift without a clear shared edge. | Some elements align, but the system is inconsistent. | Most elements share a clear alignment structure. | The repeated alignment is intentional and clearly holds the layout together. |
| Spacing and whitespace | Gaps feel random, cramped, or uneven. | Spacing is somewhat controlled but still messy in places. | Spacing generally separates groups and gives the page room. | Whitespace creates clear structure, rhythm, and breathing room. |
| Reading order | The viewer has to search for the main sequence. | The order is partly clear but still uncertain. | The page reads in a mostly logical order. | The reading order is immediate and easy to follow. |
| Grouping and clarity | Related items do not feel connected. | Some grouping exists, but several areas feel disconnected. | Related information is mostly grouped in a sensible way. | Grouping is obvious and each section feels purposeful. |
| Readability and contrast | Text is difficult to read or too cramped. | Readability works in some spots but not others. | Text remains readable and comfortably spaced. | Readability is strong and the spacing supports it well. |
