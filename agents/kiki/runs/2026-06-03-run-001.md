## Key Learning Notes

- Visual hierarchy is the order in which a viewer reads a design, and it becomes clearer when one element has more visual weight than the others.
- Size and contrast are the quickest beginner tools for directing attention, but they need moderation so the page does not become chaotic.
- Alignment is not decoration; it reduces uncertainty and helps the viewer understand how the pieces belong together.

## Studio Process Principles

- Start with the message, then choose the visual hierarchy that makes that message obvious.
- Treat process as part of the work: experiment, compare variations, and keep notes about what changed and why.

## Beginner Assignment

### Title

One-Message Event Flyer

### Learning Objective

Create a single-page flyer with one clear focal point and a readable information order using size, contrast, spacing, and alignment.

### Estimated Time

45-60 minutes.

### Materials / Tools

- Figma Free or Canva Free
- A simple grid or layout guides
- A text editor for notes
- Optional: a contrast checker

### Design Brief

Design a flyer for a fictional community event with one headline, one short supporting sentence, one date/location line, and one call to action. The flyer should be readable in three seconds from a normal viewing distance.

### Steps

1. Write the content first: headline, support line, date/location, call to action.
2. Choose one focal point and make it clearly larger or more prominent than the rest.
3. Use layout guides to align the text blocks and keep spacing consistent.
4. Build a first draft, then reduce any extra emphasis that competes with the headline.
5. Check whether the reading order still feels obvious after stepping back from the page.

### Constraints

- Use only one page.
- Use no more than two font families.
- Use one strong visual focal point only.
- Keep the copy short and specific.

### Deliverables

- One finished flyer image or PDF.
- One short note describing what the focal point is and why.

### Reflection Questions

- What did you choose as the first thing a viewer should notice?
- What did you remove or reduce so that first reading path became clearer?

### Optional Stretch Challenge

Make a second version that changes only one hierarchy variable, such as size or contrast, and compare which version reads faster.

## Critique Rubric

| Criterion | 1 - Needs Work | 2 - Developing | 3 - Solid Beginner Attempt | 4 - Strong Beginner Work |
|---|---|---|---|---|
| Visual hierarchy | The page has no clear focal point and the viewer must search for the main message. | A focal point exists, but it competes with other elements. | The main message is noticeable and most supporting information stays secondary. | The reading order is immediate and the focal point is unmistakable. |
| Alignment | Text blocks feel scattered or accidental. | Some elements align, but others drift without a system. | Major elements share a consistent alignment structure. | Alignment is clean, intentional, and clearly supports the layout. |
| Spacing | Gaps feel random or cramped. | Spacing is somewhat consistent but not disciplined. | Spacing mostly supports breathing room and separation. | Spacing creates clear grouping and an orderly rhythm. |
| Contrast | Text or key content is hard to distinguish from the background. | Contrast works in some places but fails in others. | Important text is readable and the focal point stands out. | Contrast is used carefully to guide attention and keep text readable. |
| Clarity of message | The flyer is hard to understand quickly. | The message is present but not immediate. | The event details are understandable at a glance. | The message is obvious, concise, and easy to act on. |
| Revision quality | No meaningful revision is made after the first draft. | A few changes are made, but they do not address the main issue. | The second version improves the biggest weaknesses. | Revisions clearly respond to critique and strengthen the design. |
